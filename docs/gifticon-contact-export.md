# 기프티콘 전화번호·이메일 관리자 전달

기프티콘 구매자 명단은 기존 `camnect.official@gmail.com` 수신 설정과 관리자 메일 재시도를 유지한다. 첨부 XLSX에 `buyerName`, `buyerEmail`, `buyerPhone`, `recipientPhone`, `recipientEmail`을 함께 제공한다. 모든 연락처는 주문 시점의 스냅샷이며 내보내기 시 현재 계정으로 덮어쓰지 않는다. 전화번호 셀은 문자열로 저장하여 앞자리 0을 유지한다.

- `READY`: 수신 전화번호와 이메일이 모두 유효. `recipientPhone`으로 발송하고 이메일을 함께 참고한다.
- `PHONE_REQUIRED` / `EMAIL_REQUIRED` / `CONTACT_REQUIRED`: 해당 수신 연락처를 관리자에게 확인한 뒤 처리한다. 구매자 정보로 임의 대체하지 않는다.
- `buyerPhone`은 계정 번호를 수집하는 방식에서만 저장한다. 구매 시 입력한 수신 번호를 구매자 번호로 추정하지 않는다.

Flyway V18은 기존 V13을 수정하지 않고 nullable 전화번호 스냅샷 컬럼을 추가한다. V13에서 삭제된 값은 복구하지 않으며 과거 주문은 관리자 확인 대상으로 남는다. 이미 제출한 배치를 재전송하지 않고, 재시도 대기 중인 구형 엑셀만 새 컬럼으로 재생성한다. 기존 포인트·구매·배치 상태는 그대로 보존한다.

이 공통 변경 위에 회원가입 번호 기본값 방식과 구매별 직접 입력 방식을 각각 별도 PR로 구성한다. 두 PR은 대안이므로 하나를 선택한다. 실제 Gmail 발송이나 운영 DB 변경은 PR 작성 과정에서 수행하지 않는다.
