# 구현 검증 기록

## 자동 업로드 추가 검증

2026-10-28 후속 구현으로 자동 등록 API와 Python 게시기를 연결했다. `camnect` 계정을 작성자로 사용하도록 기본 설정했다.

- 실제 수집한 49개를 **실제 Spring 테스트 HTTP 서버와 H2 DB**에 Python으로 자동 업로드했다.
- 생성된 활동 49개가 `category=EXTERNAL` 목록과 상세 조회에 나타남을 확인했다. 인증된 `GET /api/activity?category=EXTERNAL&size=100`에서도 49개를 확인했다.
- 같은 49개를 다시 전송한 결과 `UNCHANGED: 49`, 총 활동 수 49개를 유지했다.
- 본문·썸네일 파일 저장과 CDN URL 응답, 정확한 마감 시각을 확인했다.
- 자동 등록 API가 기존 사용자 JWT 인증을 우회하는 범위는 정확히 한 경로이며 그 경로는 별도 HMAC로 검증한다. 다른 활동 API는 여전히 사용자 인증이 필요함을 확인했다.
- Python 자동 테스트 31개 통과. 서버 활동/회원 인증/마이그레이션 회귀 테스트 70개 통과(실제 49개 전송 사례 포함). `camnect` 이름 조회, 일반 계정 승격 금지, 긴 한글/이모지 본문의 저장 용량 제한도 검증했다.
- 운영 API/DB에는 아직 업로드하지 않았다. 이 검증은 운영 활성화나 AWS 배포 완료를 의미하지 않는다.

아래 내용은 최초 수집기 검증 기록이다. 자동 업로드의 최신 절차와 계약은 [AUTO_UPLOAD.md](AUTO_UPLOAD.md)를 따른다.

검증일: 2026-10-28 KST. 로컬 Python 3.12에서 실행했다. AWS 템플릿 런타임은 Python 3.13이며 CI도 3.13을 사용하도록 작성했다. CI 원격 실행 및 AWS 배포는 아직 수행하지 않았다.

## 실제 게시판 수집

- 목록 4페이지에서 고유 게시글 49개를 발견했다.
- 여러 실행에 걸쳐 49개 전체의 상세 데이터와 원문 HTML을 저장했다.
- 검수 큐의 게시글 수와 고유 ID 수가 모두 49개임을 확인했다.
- 미디어 항목 58개 다운로드 성공, 8MB 초과 2개 검수 대기, 외부 호스트 미디어 7개는 URL만 기록했다. 미디어 항목 수는 게시글별 집계이므로 동일 파일을 여러 글이 참조하면 중복 집계된다.
- 날짜 검수가 필요한 글 39개, 이미지 중심 글 11개였다. 분류는 중복될 수 있다. 이 결과는 OCR까지 완료된 데이터가 아니다.
- 수영구청 경진대회 글 `1210911`의 마감은 `2026-10-30T18:00:00+09:00`로 보존되었고, 확인되지 않은 모집 시작일은 null이다.
- 저장된 49개 원문을 다시 파싱하여 제목·본문·이미지·첨부 링크·외부 링크·신청기간 후보가 저장 결과와 일치함을 검증했다. 저장된 정규화 데이터의 SHA-256도 재검증했다.

초기 검증에서 JPG의 `application/x-msdownload` 응답, 대용량 파일, 실행당 다운로드 한도에 따른 실패를 확인했다. 파일 서명 판별과 대용량 검수 분기를 보완하고 후속 실행으로 미수집 글을 채웠다. 한 번의 무제한 실행으로 49개가 모두 성공한 것으로 해석하지 않는다.

## 자동 검증

- `python -m unittest discover -s tests -v`: **23개 통과**.
